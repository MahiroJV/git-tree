# Security Policy

## Supported Versions

Only latest release get security fix. Old version, no fix, update instead.

| Version | Supported |
|---------|-----------|
| Latest release | ✅ |
| Older release | ❌ |

## Reporting a Vulnerability

Found security bug? **Do not open public issue.** Public issue tell bad actor before fix ready.

Instead, use one of this:

1. **GitHub Security Advisory** (preferred) — go to [Security tab](https://github.com/MahiroJV/git-tree/security/advisories/new), click "Report a vulnerability".
2. **Email** — mahirmehtizade35@gmail.com. Put `[git-tree security]` in subject.

### What to include

- What kind of issue (e.g. path traversal, unsafe command exec, memory issue)
- Steps to reproduce
- Affected version / commit
- Impact — what attacker can do

### What happen next

- You get response within few days.
- If confirm real bug, fix work start. You get credit in release note, unless you ask stay anonymous.
- If not security issue, we point you to normal issue tracker instead.

Thanks for help keep git-tree safe.
